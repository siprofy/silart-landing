# Требования: карусель отзывов клиентов

- **Дата:** 2026-11-12
- **Статус:** Компонент готов, ждёт контента

## Задача

На главной — карусель с отзывами клиентов, между блоками «Компания» и «Подберём оборудование».

## Контент

На silart.com отзывов клиентов нет (есть только цифра «700+ компаний» без названий).
**Выдуманные отзывы не публикуем**: сайт реальной компании, вымышленные отзывы вводят клиентов
в заблуждение и нарушают закон о рекламе.

Источник отзывов — владелец: благодарственные письма и отзывы клиентов с их согласием на публикацию.
Данные — в `src/data/testimonials.ts`: текст, автор, должность, компания, проект.

- Пока список пуст, секции нет в production-сборке.
- В `npm run dev` показываются примеры с пометкой «Пример» — для проверки вёрстки.

## Поведение

- Без внешних библиотек: CSS scroll-snap + небольшой скрипт.
- 3 карточки на экране на десктопе, 2 — на планшете, 1 с краем следующей — на телефоне.
- Листание: свайп, кнопки «назад/вперёд», точки, стрелки клавиатуры (при фокусе на ленте).
- Кнопки неактивны на краях ленты; если все отзывы помещаются, навигация скрыта.
- Без автопрокрутки (мешает читать); при `prefers-reduced-motion` — без плавной анимации.
- Доступность: `role="region"` + `aria-roledescription="карусель"`, слайды подписаны «N из M».
