# ADR-0004: Визуальный язык «тепловая карта» и светлая/тёмная темы

- **Статус:** Принято
- **Дата:** 2026-11-07
- **Связанные ADR:** [ADR-0003](0003-static-site-generator-choice.md)

## Контекст

Silart — технологическая компания, сайт должен выглядеть технологично и не как шаблон.
Обязательное требование — тёмная тема. Аудитория — инженеры, интеграторы, снабженцы:
им нужно быстро найти серию или запросить подбор.

## Рассмотренные варианты

1. Типовой «SaaS»-стиль: одинаковые скруглённые карточки, градиентные пятна, неоновый акцент
   на почти чёрном фоне.
2. Визуальный язык из предметной области — тепловизионная съёмка шкафа: температурная шкала
   как основная цветовая система и интерактивная тепловая карта как главный элемент страницы.

## Решение

Вариант 2.

- **Главный элемент** — интерактивная тепловая карта шкафа в первом экране
  (`src/components/ThermalDemo.astro`): сценарии «без защиты / вентилятор / кондиционер /
  нагреватель зимой» и щуп температуры под курсором. Модель упрощённая и подписана как
  иллюстрация, а не расчёт.
- **Цвет** — тепловая шкала (`--t-*` в `src/styles/global.css`) несёт смысл: ей же помечены
  направления каталога (кондиционеры — холодные, нагреватели — горячие).
  Остальная палитра — сдержанная: стальной светлый фон и сине-графитовый тёмный.
- **Шрифт** — одно семейство Geologica (вариативный, кириллица), без отдельного моноширинного.
- **Движение** — одна анимация при загрузке (шкаф «прогревается»), остальное — только
  в ответ на действия пользователя; `prefers-reduced-motion` отключает анимацию.
- **Темы** — по умолчанию следуем системной настройке, переключатель в шапке сохраняет выбор
  в `localStorage`. Тема применяется скриптом в `<head>` до отрисовки, без мигания.
  Все цвета — только через токены, компоненты не содержат собственных цветов темы.

## Последствия

- Новые страницы обязаны брать цвета только из токенов, иначе сломается одна из тем.
- Тепловая карта — клиентский скрипт (~3 КБ), остальная страница без JavaScript.
- Шрифт грузится с Google Fonts; при переходе на самостоятельный хостинг шрифтов — отдельное решение.
