# Architecture Decision Records (ADR)

Здесь фиксируются значимые решения по проекту: архитектура, стек, хостинг, структура контента и URL,
интеграции. Почему именно ADR — см. [ADR-0001](0001-record-architecture-decisions.md).

## Как добавить решение

1. Скопировать [template.md](template.md) в файл `NNNN-kratkoe-nazvanie.md`
   (следующий свободный номер, kebab-case латиницей).
2. Заполнить, поставить статус **Предложено**.
3. Обсудить, при согласии сменить статус на **Принято** и добавить строку в индекс ниже.
4. Принятые ADR не переписываются. Если решение меняется — создаётся новый ADR,
   а у старого статус меняется на **Заменено [ADR-NNNN](...)**.

Статусы: Предложено · Принято · Отклонено · Устарело · Заменено.
