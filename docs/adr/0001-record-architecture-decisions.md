# ADR-0001: Фиксировать архитектурные решения в ADR

- **Статус:** Принято
- **Дата:** 2026-11-07
- **Связанные ADR:** —

## Контекст

Сайт будет развиваться постепенно: лендинг, затем каталог продукции, информационные разделы.
Без записанных решений со временем теряется ответ на вопрос «почему сделано именно так»,
и одни и те же вопросы обсуждаются заново.

## Решение

Все значимые решения оформляются как Architecture Decision Records (формат Майкла Найгарда,
с разделом альтернатив) в папке `docs/adr/`. Процесс и шаблон описаны в [README](README.md).

## Последствия

- История решений хранится в репозитории рядом с кодом и проходит через git.
- Новый участник может восстановить контекст по индексу ADR.
- На каждое значимое решение тратится немного времени на запись.
